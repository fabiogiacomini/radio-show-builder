# Security

This is a single-user local application. Do not expose its port to the public internet.

API keys are held in memory and not saved in projects or logs. Keep the launch URL, local production folder and backups private.

Use trusted FFmpeg builds and keep dependencies updated. Source installations use a separately installed FFmpeg. Portable downloads include a minimal FFmpeg built from the verified source archives supplied with the release; it retains its own license. The source repository contains the build scripts, not vendored binaries.

Use the repository's private vulnerability reporting when available. Do not place real credentials, recordings or personal data in a public issue.
